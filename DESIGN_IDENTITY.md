# Identity brief

Reciprocal Draft is a public tabletop, not a form dashboard. Its first viewport is an empty dotted field between two physical racks. Opening a table, placing a requirement, placing a capability, and finding an existing table each happen in a focused sheet; raw contract arguments never remain pinned to the screen. Consensus returns a central set of paired slips and draws orange threads across the field. The voice is social and invitational, the motion is lateral, and the result is spatial rather than numerical.
