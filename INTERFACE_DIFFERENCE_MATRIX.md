# Interface difference

| Dimension | Reciprocal Draft | Mandate Fuse |
|---|---|---|
| Input journey | Focused sheets place one need or offer at a time | Four full-screen scenes: engrave, bind, seal, burn |
| Composition | Dotted tabletop between two physical slip racks | Sequential instrument with no persistent form controls |
| Primary action | Draw mutual threads across the table | Press a circular seal, then pull a single lever |
| Result | Paired slips connected spatially | Burned fuse plus a sealed audit receipt |
| Mobile behavior | Table moves above stacked racks | Scenes remain linear; action chamber stacks after fuse |
